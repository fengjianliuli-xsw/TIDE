# TIDE 有效步长评分验证

设计冻结于 2026-11-13，结果生成前。主实验是固定检查点的单步反事实回放。每个候选的真实表现均可测量。

## 样本与输入

五个 E003 问题均使用原配置、CPU float64 单线程、原种子 0/1/2 和对应训练点。主层使用 E003/main 下 initial（零 Adam 状态）及 always 终点（真实 m、v、count）。使用 E003 原有逐块容差。检查两个快照间参数变化，并标记相同状态。主结果按问题和种子配对，候选与检查点是重复观测。

自然训练补充层从每个 initial 起跑，普通 Adam 以 PDE+100×各保护项 MSE 之和、lr=0.001 继续训练，在第10、40、120步保留参数与完整状态。仍用原容差，起点已越界的样本记数并排除出主保护问题。对所有自然状态另做局部容差诊断，逐块 cap=max(1e-4,1.1×当前 MSE)，单列表达，不混入主结果。

同一检查点生成三个实际 Adam 更新，梯度权重 0、1、100，lr=0.001，动量等沿用 E003。主分析完整步长倍率为1。另作倍率4压力试验，固定相同方向，仅放大提案，结果单列。禁止事后挑方向、阈值或种子。主层、自然层分别报告。

## 选择器

所有方法共享候选、探测点、保护阈值、实际参数状态和各方向同一个二次模型步长。固定方向 ID 打破平局。求解 [0,1] 上 aα+qα²≤h，q为归一化残差JVP的平方和；多个块取交集。线性可行步长由 q=0 同一规则给出。h=0、a≤0、q=0、极小步长、浮点容差需明确，根用数值稳定形式。候选 p=-g_PDE·d>0；零步是显式回退。比较下列四项。

1. 完整步长收益 p 降序，按共同模型步长试算，接受首个真实可行且 PDE 下降的提案。
2. 全量 TIDE 计算 S=pα，按 S 降序复核。
3. 按需 TIDE 使用 U=pα_linear 作上界，按 U 降序逐个补充 q，直到剩余上界无法超过当前 S。平局以相同ID处理；浮点近似平局保守扩展。首选被真实复核拒绝时删除该项，重用已求出的 S，恢复搜索。不得读取全量版或 oracle 的曲率/结果。核对首次模型赢家、最终提交、步长、真实收益，全量与按需须等价。
4. 有限集合真实试算参考。评估上述每个合格方向在同一模型步长上的真实约束与PDE，选真实可行的最大收益，加入零步。参考最优只限这个集合。

## 测量与交付

保存逐候选的 p/a/q、h、上界、模型步长、预测收益、真实增量、保护集及独立集误差；逐决策保存首次选择与最终选择、拒绝、方向ID、步长及实际参数位移。标记同方向或近乎重合的提案（报告夹角或余弦，原始ID仍保留）。以相同方向步长比较排名，区分换方向、仅由提交回退导致的差异、候选集合确无有效更新。主指标包括方向改变次数、换向子集中的真实收益胜/平/负和配对差、相对有限集合参考的损失、复核通过率。跨方程汇总收益使用除以起点PDE MSE的归一化值并保留分方程原尺度。

在每个主检查点预热后轮换执行顺序，至少3次重复，报告实际 JVP 数、实际复核数、全量/按需选择与复核时间、包含共同梯度与候选生成的时间；oracle标注参考成本口径。计时避免文件I/O、共享跨方法 JVP 或将审计计算混入按需版。定向例子校验评分确实换向、上界相等、复核失败后第二名及零步回退。最终给出可复现命令、代码、配置与源版本、原始表和中文实验报告。报告说明哪些结果属于本轮回放，哪些长程收敛问题仍待验证。
