# TIDE 五个时间演化 PINN 测试任务

2026-11-14。状态为实验设计。NLS 与 Gray–Scott 已有 E004 单步回放，三个新增任务待验证。本组专门考察时间演化题中的 IC、BC 保护。原 E004 五题的逐题结果应并列披露，尤其保留 Helmholtz 的零收益。

## 冻结的任务组合

|问题|初边值设置与参考解|任务回答的问题|
|---|---|---|
|一维聚焦非线性薛定谔（NLS）|沿用 E003，空间区间为 [-5,5]，T=2，精确 Dirichlet 和初值均取自 sech(x) exp(it/2)。用复场相对误差，并分别报告实、虚部。|旧回放中收益最大，检查连续提交后相位和解误差是否改善。|
|二维 Gray–Scott|沿用 E003 单位周期方形、平滑初始扰动、T=2，检查周期函数值与一阶空间导数。复用已加密核对的 FFT/RK4 参考，分开报告 u、v 误差。|另一个已见信号的算例。该短时间窗只支持判断初期演化。|
|一维复 Ginzburg–Landau（CGLE）|采用 A_t=A+(1+ib)A_xx−(1+ic) abs(A)² A。自选周期实例 x∈[0,2π]，T=2，b=1，c=0.5，A(x,0)=0.6+0.25 exp(ix)+0.1 exp(−2ix)。用周期谱法计算参考解并做时空加密核对。|保留 NLS 的复场、三次非线性与相位，引入实扩散和幅值耗散。分别记录复场误差及幅值误差。|
|二维 FitzHugh–Nagumo（FHN）|取 PDEBench 的 2D diffusion-reaction，u_t=0.001 Δu+u−u³−0.005−v，v_t=0.005 Δv+u−v。用数据集随附坐标与时刻，截取 0 至 5，取文件内最小编号轨迹并在各训练种子间固定。四边分别保护两分量的零法向导数。用原始初帧作 IC，后续帧仅供测试。|保留 Gray–Scott 的双场反应扩散，引入不同的反应耦合与 Neumann 边界。记录 IC 是否能达标及两个分量各自的误差。|
|一维 Allen–Cahn|经典周期题 u_t=10⁻⁴u_xx+5(u−u³)，x∈[−1,1]，T=1，u(x,0)=x² cos(πx)。使用原作者 AC.mat 参考。初值两端斜率不匹配，IC 在 t=0 单独采样，周期导数约束取 t>0。|保留时间演化与多约束，去掉多输出耦合，观察标量界面形成时能否也出现有效换向。|

CGLE 采用自定义平滑多模态初值，避免把一个解析平面波当成主要证据。其方程及 PINN 应用参见 [ASPEN 原文](https://arxiv.org/html/2512.03290v4)。FHN 参见 [PDEBench 论文](https://arxiv.org/abs/2210.07182) 与 [作者生成器](https://raw.githubusercontent.com/pdebench/PDEBench/main/pdebench/data_gen/src/sim_diff_react.py)。Allen–Cahn 参见 [Raissi 等原文](https://faculty.sites.iastate.edu/hliu/files/inline-files/PINN_RPK_2019_1.pdf)。新增题应首先核对参考场、坐标顺序、初值和边界算子，再启动比较。

## 方法与比较

1. 首先冻结局部问题。已达标保护块各有首次进入保护时固定的上限。允许单步消耗剩余裕量。候选由同一参数和优化器状态生成。对每个 PDE 一阶收益 p>0 的候选，用保护残差的 Gauss–Newton 二次模型求可行步长 α，然后按 pα 评分。原型用 E004 的启动容差进行复现，逐题公布实际数值及独立点启动状态。用于声称达到物理精度的实验要预先给出按量纲或参考尺度归一化的目标。
2. 固定探针点和稳定平局规则，按线性上界排序。只有剩余上界仍可能胜出才计算 JVP。真实试算失败后继续评估剩余候选，只提交入选试步及对应的优化器状态。所有候选失败时记零步。确定性等价命题覆盖同一可行起点、同一候选集、同一比较精度及同一复核规则。它只保证复现全量代理评分的决策序列。
3. 先在 NLS、Gray–Scott 做配对连续训练。含标准加权 Adam、按 PDE 斜率排序并共用 GN 步长的 E004 基线、全量 TIDE、按需 TIDE。另做线性步长/线性评分加真实验证的消融，以及直接在少量保护点前向试算的成本对照。所有方法使用相同的训练初值、配点与配对种子；前四组分别隔离普通训练、排序与按需计算的贡献。直接试算组必须计入所有试算和回退。
4. 先用旧题单独开发。定下容差、训练时长、检查点和候选规则后，在三个新增题上按同一规程验证，保留全部结果。设置等时间主比较和同步数诊断。不同方法独立延续自己的真实轨迹，择向差异另在共享快照上回放。至少五个配对训练种子，逐题给出逐种子值；同一训练中的连续快照不作独立重复。
5. 报告固定时间的相对解误差、逐分量误差、独立 IC 和 BC 超限比例与超限幅度、端到端实耗时。区分启动就已超限和提交后新超限。记录每个候选的 PDE 斜率、可行步长、限制步长的约束块、最终方向、零步和真实复核次数；记录小探针 JVP 与直接试算的耗时。审计集只评估，不能用于选择方向或筛除轨迹。未达到可比保护精度的轨迹单列，计入总运行数。
6. 若两旧题在对等时间及可比保护精度下出现可重复的解误差收益，转入三新增题复验。若独立点经常越界，优先验证保护点代表性；若可行候选稀少或多个更新几乎共线，优先做候选生成消融；若全量与按需一致但前向试算更快，报告不同保护算子与候选数量下的实测成本。任何后续改动须与本轮冻结版分别命名和报告。
