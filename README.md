# TIDE — PINN 约束感知方向选择实验

TIDE（Tolerance-Informed Direction Evaluation）研究一个问题：在已达标的初值或边界误差允许有限反弹时，能否利用约束曲率，以更低成本选择更有价值的 PDE 更新？

**本仓库归档完整的探索过程与负结果。** 按需版能在已检查的状态中复现全量曲率选择，并减少 JVP。在线实验中，原版、加入缩步的版本和二维修正版均发生提前停滞。目前证据支持结束将 TIDE 作为主优化器方案的开发。

|阶段|实验|主要发现|
|---|---|---|
|E001–E002|Poisson 机制、切向候选、预算与曲率探索|允许有限反弹和改变候选集能推进局部优化，曲率收益依赖候选和成本|
|E003|五个 PDE 上的按需保护曲率|计算可减少，固定探针与独立约束精度存在差距|
|E004|相同参数与优化器状态的反事实回放|240 配置中按需与全量决定相同；主层 JVP 约减少 27.3%，决策耗时约减少 26.8%|
|E005|五题配对连续训练|24 个有效初态，96 条轨迹；按需版 16/24 零提交|
|E006|经验平台、停滞与时间截尾比较|Adam 14/24 稳定达标，15/24 平台；TIDE 加缩步 0/24 达标，24/24 停滞|
|E007|24 个旧停滞状态的二维平面回放|固定平面中二阶选角改善部分单步真实收益|
|E008|TIDE-2D 两组真实训练|二阶选角相对线性选角的终点误差 12 胜/1 平/11 负；两组各 24/24 停滞，0/24 达标|

先读[总报告](reports/TIDE实验总报告.md)，再看[复现说明](reports/复现说明.md)。各轮冻结协议、中文报告、独立验收和逐种子 CSV 都在 experiments 对应子目录。

## 仓库内容

- experiments 保留原实验的相对目录、源代码、报告、JSON/CSV 汇总和图。E001 的脚本在目录根，其原始数据在 raw。
- manifests 记录公开源文件与原始附件的 SHA256，以及附件大小、版本。
- GitHub Release experiments-2026-11-15 的 tide-original-artifacts.zip 包含权重、参考场、逐步日志和原始文件，解压后补充到 experiments。实验附件包含 E004 回放快照、E005 配对初态和后续复算所需的所有已归档状态。

Python 3.11 下安装 requirements.txt 后，可先执行：

```powershell
python tools/verify_manifest.py
python tools/fetch_artifacts.py
python experiments/e008_tide2d/train.py --selftest
python experiments/e008_tide2d/verify_training.py
```

历史记录中的 F:/RA 路径是实际实验位置。当前脚本大多按自身路径定位输入，发布包保留原目录关系；重跑前请阅读复现说明，已有结果会被部分脚本复用。

## 结果解释

单步回放收益、最终参考解误差、固定点安全、独立点精度和达到平台分别报告。E006 的平台采用有限窗口和固定分辨率；仍到时间上限的轨迹作为截尾记录。FHN 一个种子启动失败计入计划分母；跨轮机器并发不同，历史耗时仅作背景。

本次整理保留历史文件与其哈希；总报告提供统一解释。归档时间为 2026-11-15。作者未在此归档中新增软件许可证，第三方参考数据的来源见复现说明。
