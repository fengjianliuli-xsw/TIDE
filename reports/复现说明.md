# 复现与附件

## 环境及数据恢复

原运行环境为 Windows、Python 3.11、CPU float64。requirements.txt 固定已测量的主要库版本，包含 CPU PyTorch 实际版本去除 +cpu 后的版本号。若默认镜像无对应 PyTorch 轮子，使用 PyTorch CPU 官方索引取得对应版本；安装后记录设备与版本。不同 CPU、平台和并发会改变计时停止时的步数。

在仓库根运行 python tools/fetch_artifacts.py 恢复完整附件。也可从本仓库 GitHub Release experiments-2026-11-15 手工下载 tide-original-artifacts.zip，再传给 --archive。该脚本校验 SHA256 后解压，恢复与公开源码一一匹配的原始实验文件。历史报告、源快照及绝对路径原样保留。运行 python tools/verify_manifest.py --artifacts 可核查 2,158 个原始文件。

## 先验收已有结果

python tools/verify_manifest.py

这些脚本读取已存状态并做独立复算，不需要完整重训。原始版本的验收脚本会在相应实验目录写复算输出。PyTorch 状态只加载你信任的本仓库实验附件。

## 完整重训

先做新的单独克隆或复制已恢复目录再训练。在 E005–E008 中，存在的 .pt 会被自动复用。重训前将目标实验 results/results_long 输出目录另存至备份，并仅清理该输出目录。各轮输入依赖如下。

|阶段|依赖|入口|
|---|---|---|
|E001|解析 Poisson|experiments/run_experiment.py --tag 新名称|
|E002|解析 Poisson|experiments/e002_design_study 下各轮脚本与实验记录|
|E003|Gray–Scott 参考|bench.py --tag 新名称 --steps 120|
|E004|E003 的 main 初态/终态|replay.py|
|E005|E003 参考，AC.mat，官方 FHN 首轨，CGLE 参考|longrun.py --steps 1000|
|E006|E005 的 initial.pt 与参考场|converge.py --worker i --workers 3；首阶段结束后按固定 extension_jobs.json 续跑 --hard 360 --worker i --workers 6|
|E007|E006 的终态|frozen_plane.py|
|E008|E005 的 initial.pt、E006 公共验证规则|train.py --worker i --workers 8；每worker先120秒、对全部截尾自动续到360秒|

i 分别遍历 0 到 workers−1，每个进程 torch 单线程。E006 仓库中的 extension_jobs.json 是历史首轮截尾名单。重训时必须用新首轮实际 stop=time_censored 的结果生成新的冻结名单，再启动续跑。重训不会逐位复现按 wall clock 判定的平台或检查时间，科学比较应同时看验证轨迹、终止类别、实际步数与精度。

## 第三方参考场及来源

- NLS 为解析 sech(x) exp(it/2)，有限空间区间上使用解析 Dirichlet，时间终点 2。
- Gray–Scott 沿用 E003 自生成周期 Fourier/RK4 参考，含32/64网格核查。CGLE 使用自选平滑多模态初值和自生成积分因子 RK4 参考，另有 DOP853 独立核查。各自方程及参数在实验代码中。
- Allen–Cahn 使用 [Raissi 原始仓库的 AC.mat](https://github.com/maziarraissi/PINNs/blob/master/main/Data/AC.mat)，SHA256 266e97eedd9ef543d7f6d370fa5f06388761aa7da2b97e476562dcf1d644a175。原仓库的许可见作者仓库。本次也用独立谱分裂法核对。
- FHN 从 [PDEBench 官方数据集](https://doi.org/10.18419/darus-2986) 中的 2D/diffusion-reaction/2D_diff-react_NA_NA.h5（file id 133017）抽取组 0000。作者为 Makoto Takamoto 等，数据元信息列明 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。本次改动为提取单组和另存 float64 NPZ，附件 fhn_first.h5 的来源和 SHA256 见 data/fhn_source.json。主实验使用官方 101×128×128×2 发布轨迹，IC 固定双线性插值。早先50网格生成器结果仅作诊断，未代替官方主轨。

附件不包含可重建的 Python 缓存、重复梯度先导目录和与方法评测无关的投稿时程资料。原先的哈希文件对应当时记录的源版本；后续可追溯实现修改的解释保留在各轮报告中，公开打包版本另有发布清单。
